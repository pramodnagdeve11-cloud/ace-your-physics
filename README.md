## 🛠️ Local Development & Preview

No build steps, package managers, or compilers required! This project runs natively in all modern web browsers.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/<your-username>/ace-your-physics.git
   cd ace-your-physics
   ```

2. **Open the website:**
   - Double-click `index.html` or open it with your favorite browser.
   - Or use VS Code's **Live Server** extension.

## 🌐 Deploy to GitHub Pages (Free Hosting)

1. Push this repository to GitHub:
   ```bash
   git init -b main
   git add .
   git commit -m "Initial commit: Ace Your Physics website"
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git push -u origin main
   ```
2. On GitHub, navigate to **Settings** > **Pages**.
3. Under **Branch**, select `main` and root directory `/ (root)`.
4. Click **Save**. Your website will be live in ~1 minute at `https://<your-username>.github.io/<repo-name>/`!
